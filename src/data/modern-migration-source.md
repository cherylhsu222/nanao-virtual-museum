# 舊社到現址資料依據

GPX：原 migration-map 指向的 https://github.com/Cheylhsu888/nanao-gpx-data ，保留原始檔內容，顯示時依目的地判斷方向。

關係沿用原展品遷村章節（流興→金岳、哈卡巴里斯→武塔、舊金洋→金洋、比亞毫→碧侯、莫瑤→澳花）。奎諾斯→金洋來自金洋章節；庫巴博、各姆姆→南澳來自 PLACES 的南澳村介紹。

原 ALL_EDGES e11 的起點「比亞毫社」與同一筆 label 及澳花章節「莫瑤社→澳花」矛盾，因此此版使用章節與 GPX 檔名一致的莫瑤社。

金洋 GPX 檔名寫奎諾斯，原展品金洋章節使用它呈現舊金洋遷村；本版保留原展品路線，奎諾斯另以概念關係線連結，不捏造第二條 GPX。GPX 端點與 PLACES 可能略有偏差，不加直線補接。

南澳村只顯示有文字依据的關係線，東岳村沒有來源明確的舊社連結，保留節點但不造路線。細虛線是概念關係，暖棕實線才是 GPX。
